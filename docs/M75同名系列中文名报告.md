# M75：同名系列的中文名归属（东方定助 / 东方仗助 / 吉良吉影）

> 用户反馈：
> 「东方定助好像搜不到，因为他的名字和东方仗助是一样的吗？东方仗士文也是。」

用户猜对了一半：**英文名确实一样**，但中文名不同 —— 而这正是问题所在。

---

## 1. 三个根因

### 1.1 `extract_nihongo()` 只取英文名，JoJolion 条目被整条跳过

中文维基「各部条目」用 `{{nihongo|中文|日文|英文}}` 列角色。但 **JoJolion 部的模板大多不带英文名**：

```
{{nihongo|東方定助|東方 定助（ひがしかた じょうすけ）}}
```

而代码是：

```python
en = clean_cell(args[2]) if len(args) >= 3 else ""
...
for zh, en in nihongo:
    if not en: continue      # ← 这些条目全部被跳过
```

后果：第 8 部 **4 个「与前面部同名」的角色**（东方定助 / 吉良吉影 / 仗世文 / 伴子）
**一个中文名都拿不到**。

### 1.2 中文名挂错人

`josuke_higashikata`（第 4 部）同时挂着「东方仗助」**和**「东方定助」，
而 `josuke_higashikata_jojolion`（第 8 部）是 `None`。

因为路径 A/B 都按**英文名**匹配，而两部的英文名完全相同
（`Josuke Higashikata` / `Josuke Higashikata (JoJolion)`，归一化后一样）→ 全落到第 4 部。

### 1.3 就算两个都有名字，搜索只出第一个

`by_name` 是 `dict[str, str]`，构建时 `setdefault` → 同一个名字只留第一个 cid。
「吉良吉影」在第 4/8 部**都对**，但搜索只出第 4 部。

---

## 2. 修法：用**日文名**匹配

日文名有两个关键性质：

| 性质 | 说明 |
|---|---|
| **同源** | 源站的 `name_ja` ↔ 中文维基 nihongo 的第 2 参数，同一个名字的两种写法 |
| **能区分同名系列** | 「東方 仗助」vs「東方 定助」、「東方 朋子」vs「東方 伴子」 |

实测对照：

| 角色 | `name_ja`（源站） | 中文维基 nihongo |
|---|---|---|
| 东方仗助（第4部） | `東方 仗助` | — |
| **东方定助（第8部）** | `東方 定助` | `東方 定助（ひがしかた じょうすけ）` |
| **空条仗世文** | — | `空条 仗世文（くうじょう じょせふみ）` |
| 东方朋子（第4部） | `東方 朋子` | — |
| 东方伴子（第8部） | `東方 伴子` | （源缺） |
| 吉良吉影（第4/8部） | `吉良 吉影`（**两边相同**） | `吉良 吉影` |

具体改动：

1. `extract_nihongo()` 返回 `(中文, 日文, 英文)` 三元组（原来只返 `(中文, 英文)`）
2. 新增 `ja_key()`：去括号假名注音 + 去空格 + 繁转简
   （`東方 定助（ひがしかた…）` → `东方定助`）
3. 建 `char_by_ja` 索引（**多值** —— 第 4/8 部吉良吉影日文名完全相同，两边都该拿名字）
4. **日文名优先于英文名**：因为英文名对同名系列**没有区分力**

结果：路径 E 命中 **99 条**，覆盖 216 → **236**。

---

## 3. 搜索层的两处配套修改

### 3.1 精确名也可能一对多

`match()` 里补一步：命中的名字再用 `build_char_alias_index()`（M74 建的多值索引）展开，
把同名的全部 cid 拉进来。

```
「吉良吉影」→ yoshikage_kira（第4部）+ yoshikage_kira_jojolion（第8部）
```

### 3.2 排除「被更长命中名包含」的短名

「吉良吉影」还会命中 `holy_joestar_kira` 的简称「吉良」
（来自「吉良·荷莉·乔斯达」按间隔号拆出的姓氏）→ 多出一张荷莉的卡片。

判据：如果某个命中名是**同一轮另一个命中名**的真子串 → 它是噪声。
（不影响「东方」这类独立查询 —— 搜「东方」时没有任何更长的命中名包含它。）

## 4. 效果

| 查询 | 修前 | 修后 |
|---|---|---|
| 东方定助 | 查不到 | **第 8 部**（josuke_higashikata_jojolion） |
| 东方仗助 | 第 4 部 | 第 4 部 ✓（不再混着「定助」） |
| 定助是谁 | 查不到 | 第 8 部 |
| 吉良吉影 | 只出第 4 部 | **2 个候选**（第 4 部 + 第 8 部） |
| 空条仗世文 | 查不到 | josefumi_kujo |
| 中文名覆盖 | 219 | **236**（+17） |

## 5. 遗留

- **`joseph_joestar_jojolion`（仗世文·乔斯达）** 与 **`tomoko_higashikata_jojolion`（东方伴子）**
  仍无中文名 —— 中文维基的 JoJolion 条目里**没有这两条 nihongo 模板**（源缺，不是解析问题）。
- **「东方仗士文」**：用户指的实际是 **空条仗世文**（Josefumi Kujo）。他没有"东方"这个姓，
  所以搜「东方仗士文」不会命中 —— 这是**名字记错**，不是系统问题。
- 日文名匹配**依赖源站 `name_ja` 有值**；实测 374 个角色里 356 个有。
