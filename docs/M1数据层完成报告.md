## 3. ★ 渲染抓取：解决了 `ability_desc` 缺失

M1-3 报告的局限「`ability_desc` 为空」已解决。

### 为什么静态抓取拿不到

详情页正文由 JavaScript 注入，静态 HTML 里 37 个 `<p>` 全部 `text_content()` 长度 0。

### Playwright 方案

| 指标 | 结果 |
| --- | --- |
| 成功率 | **154 / 154** |
| 总字符 | **1,480,952** |
| 平均 | 9,617 字符/页 |
| 耗时 | 6 分 39 秒（限速 700ms） |

### 渲染后才能拿到的结构

```html
<div class="mw-parser-output">   ← 正文真正所在，16k+ 字符、32 个标题
  <h3>User</h3><div>Jotaro Kujo</div>
  <td class="pi-data-value" data-source="destpower">A</td>
  <div class="techBox">Ora Ora(オラオラ, Ora Ora) Debut: Chapter 119...</div>
  <li>Chapter 114: Jotaro Kujo, Part 1</li>
</div>
```

**四个关键结构发现**：

| 结构 | 用途 |
| --- | --- |
| `h3 + div` 相邻对 | 标量字段（User / Type / Origin） |
| `td[data-source]` 多次出现 | **形态链**（同一 source 多次 = 不同形态）|
| **`div.techBox`** | **招式**（jojowiki 专有，格式 `名称(读音, 罗马音, lit. "释义") Debut: 章节`）|
| `li` 以 `Chapter N:` 开头 | 战斗记录 |

## 4. ★ 招式抽取的三次迭代

这是本阶段最难的部分，走了三步弯路。

### 第一版：完全抽不到（0 条）

假设招式是 `Name : desc` 格式，扫遍所有段落和小节都没找到。

### 第二版：抽出 853 条，全是噪声

误把小节里的普通列表项当招式：
```
entity=Diamond is Unbreakabtext=Diamond is Unbreakable Episode 13: We Picked Up...
```
**剧集名以大写开头且含冒号**，被正则命中。加了 `MOVE_FALSE_POSITIVE` 排除剧集/章节名后剩 4 条——但这 4 条（`Super Strength` / `Precision`）是能力项，也不是招式。

### 第三版：找到 `div.techBox`（19 条，真实招式）

```
Ora Ora      音=オラオラ           别=Ora Ora                首发=Chapter 119
Star Finger  音=流星指刺スターフィンガー  别=Sutā Fingā, lit. "Meteor Finger Stab"  首发=Chapter 129
```

**但** `techBox` 也用于「其他替身引用卡片」（如 `"Silver Chariot" Plus`），需过滤：真招式的括号内必含片假名/罗马音/`lit.`/`Dial.`，引用卡片以引号包裹名称且无读音。

**最终**：10 个替身 / 19 条招式。**只有主角替身有 `TECHNIQUES` 小节**，这是数据源本身的特点，非抽取缺陷。

## 8. 踩坑记录（全部已修）

### 8.1 Playwright `page.evaluate` 作用域陷阱 ★

```js
.map(p => clean(p.innerText)).filter(t => t.length > 50 && !isNoise(p))
//                                                     ↑ p 已超出作用域
```

序列化成浏览器上下文执行时，箭头函数参数**不跨回调共享**。报 `ReferenceError: p is not defined`，且被 `catch` 静默吞掉导致「全部 FAIL 但无错误信息」。

**修法**：全部改写为显式 `for` 循环；**并且必须给 catch 加错误上报**，否则失败原因不可见。

### 8.2 root 选错层级

`#mw-content-text` 只有 3 个子节点，正文在第一个 `div.mw-parser-output` 里。选错 root 导致 `sections` 全空。

### 8.3 直接子节点遍历不够

`h3` 与 `p` 不一定同级（内容大的页面会包在 div 里）。改用 `createTreeWalker` 文档序遍历。

### 8.4 URL 括号 404

`Echoes_(ACT1)` 404 但 `Echoes_ACT1` 200。实现三级变体回退（原名 → 括号转下划线 → 去括号）。

### 8.5 CSV 空字符串语义

`''` 被归为 `EMPTY_SLOT`，产生 153 个假冲突。应为 `NOT_APPLICABLE`（该源未提供）。

### 8.6 跨源字面量表不完整

镜像源用了主源没有的 `unknown` / `Infi` / `situational`，规范未覆盖。
