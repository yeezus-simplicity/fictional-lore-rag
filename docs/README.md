## 阅读顺序建议

**如果你只想看结论**（推荐，约 30 分钟）：
1. [`立项书.md`](立项书.md) —— 项目要解决什么问题
2. [`选题评估.md`](选题评估.md) —— 为什么选这个方向
3. [`数据规范.md`](数据规范.md) —— 数据怎么定义的
4. 下面「阶段报告」里的**数据表格**

**如果你要写简历 / 做答辩**（约 2 小时）：
按顺序读 M1 → M4，每份报告的「验收对照」和「核心发现」两节是重点。

**如果你要复现或继续开发**：
每个模块都有 README.md，含快速开始命令。
