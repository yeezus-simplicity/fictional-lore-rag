## 二、根因与修法

### ① 地点这一侧太窄（与 M74 的角色不对称）

地点匹配从 M65 起一直是**精确**的：`名字 ⊂ 问句`。
角色在 M74 加了模糊：`问句片段 ⊂ 名字`。
两条路一宽一窄 → 「虹村宅」少一个「邸」精确落空，角色的「虹村」子串（模糊）反而命中 → 路由到 character。

修法：`locations.fuzzy_hits()`，判据**刻意很紧**：

- 片段 **≥3 个字**，且**只比地名少一个字**（`len(name) - len(seg) == 1`）
- 只在精确匹配**全空**时才跑（与 `characters.match` 同构）
- 英文侧：词是地名前缀且只差 1–2 个字母

**为什么不能放宽到 2 字**：加完模糊后「虹村」直接返回了「虹村邸」——
而「虹村」是**姓氏**（4 个角色）。这道门槛就是那时补上的。

路由侧只在问「在哪 / 什么地方」时才用地点模糊，避免把角色问句抢走。

### ② 说明文案是**固定字符串**

`character_stands` 的 note 写死为「…没有替身说明其条目未标（…）」，
挂在 2 个替身下面 → 读起来像"系统认为他没有替身"。**用户说的「对不上」就是这句。**

修法：文案跟着数据变——

- 有替身：「共 N 个替身（同一替身的不同形态或进化会并列）。数据来自源站…」
- 没有：「该角色条目未标注替身（例如第 1、2 部使用波纹的角色本来就没有替身）。」

同时补 `stands_zh`（与 `stands` 同序），前端优先显示中文名。
**刻意不举例子**：一开始写了「如黄金体验 → 黄金体验镇魂曲」，而库里的译名是
「黄金体验·镇魂歌」—— 举例举错比不举更糟。

### ③ 亲属：数据一直在，只是没人读

`families` 字段形如 `['Domenico Pucci (Twin Brother)', 'Perla Pucci (Younger Sister)']`
（212 / 368 个角色有，带括号标注的 166 条），但 `characters.py` 里没有任何一处解析它，
于是问句被当成「普奇 是谁」→ 返回档案。

新增 `services/relations.py`：

- 关系拆成**基础关系 + 长幼**两维（`Twin Brother` → `(brother, twin)`）
- 问「弟弟」而源站写 `Twin Brother` → 照给，但**明说「源站未标注长幼」**，不替用户判定
- 问「姐姐」而源站写 `Younger Sister` → **不放答案里**，单列 `contrast`：
  「另有 Perla Pucci（Younger Sister）—— 长幼与你问的相反」
- 源站根本没有该关系 → 不退化成档案，而是说明 + 列出该角色**已有**的亲属

> ★ 这里踩过一次：第一版用 `sister` 这个宽关键词命中 `Younger Sister`，
> 还补一句「源站未标注长幼」——**源站明明标了 Younger**。既答错又给了错的理由。
> → 长幼必须单独判，`twin` 视为「并列、无长幼」，不能当成「相反」。

### ④ 中文要点层（不机翻）

语料 100% 英文站。机翻会破坏证据可追溯，也违反项目的「不造词」。

`services/zh_layer.py` 只做两件事：

1. 用**库内已有中文事实**拼成中文句子（中文名 / 使用者 / 部数+部名 / 六维中文等级 / 招式数）
2. 明确标注「以上中文要点由结构化字段拼成（不是机器翻译）；描述性正文仍是源站英文原文，见下方」

示例（`黄金体验的能力是什么`）：

```
黄金体验（Gold Experience）是第 5 部《黄金之风》中乔鲁诺·乔巴拿的替身。
六维：破坏力 C、速度 A、射程 C、持续力 D、精密性 C、成长性 A。
已知招式 3 个：LIFE GIVER、LIFE SHOT、LIFE SENSOR。
```

口径：

- 缺数据写「源站未提供」，**不填 0**（与 M17 雷达图同一条）
- 招式名**保留源站原名**（中文译名不统一，不机翻）
- 状态是封闭小集合（Alive/Deceased/Retired/Missing/Unknown）→ 安全映射；
  其余带描述的长句（`Deceased (Alive as Stray Cat)`）**保持原文**，不硬拆

## 四、遗留

- 亲属名可能是源站没建条目的角色（如 `Domenico Pucci` 在本库无独立角色页）
  → 照实给名字，不编档案；未做「亲属 → 角色页」跳转
- 地点模糊只管「少一个字」；打错字（「虹村寨」）仍查不到
- 中文要点是**事实拼句**，不是译文：描述性正文仍英文
