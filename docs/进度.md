**消解**：平均置信度 0.6909 → 0.7023，脆弱结论 81.8% → 59.1%

**★★ 根因调查的核心发现**：
> **「多源交叉验证」的前提是源相互独立。**
> 实测两个 CSV 镜像源 **不独立**（topology ⊆ bogdan，
> 154 个共同条目里仅 1 处真正的等级数值分歧）
> →「两源一致」是同源复制的必然结果，**不构成交叉验证**
> → M4 的 `prefer_consensus` 策略失效，降级为 `prefer_primary`

**核心结果**：
| 判读 | 数据 |

### ✅ M7 块大小 × 生成质量（解决 M3 遗留）
- [x] 指标设计先于实验（四类指标：信息量/能否答出/精炼度/代价）
- [x] 两次修设计缺陷（数据源选错、切分基准选错）
- [x] 6 个尺寸 × 24 题实测
- [x] 权重敏感性分析
- [x] 修正 M3 的归因（「指标退化」→「装置缺陷」）

**核心发现：单指标必然偏向一方**
| 阶段 | 指标 | 偏好 | 最优解 |
|---|---|---|---|
| M3 | precision/nDCG | 大块 | 2048（全 1.0） |
| M7 第一版 | 利用率 | 小块 | 256 |
→ **两者是镜像偏差**，各只测一个维度

**推荐512**（而非加权分最高的 2048）：
- 延迟 6110ms vs 10386ms（省 41%）
- 答案 122 字 vs 232 字（省 47%）
- 空洞率 0.1250 vs 0.0417（3 条题之差）
★加权分掩盖了代价——分数最高的不一定最优

### ✅ M9 索引应用验证（闭环 M7）
- [x] 固定检索配置（与 M6 一致），只改索引切分
- [x] A/B 对照（30 题，Qwen2.5-1.5B）
- [x] ★ 修掉「低温≠确定性」的真bug
- [x] 修正自己拍的 1pp 阈值判据

**结论：M7 的推荐成立，但有代价**
| 指标 | 原始 | 512 | 变化 |
|---|---|---|---|
| 空洞率↓ | 0.5000 | **0.3000** | **−40%** |
| 被用字数↑ | 169 | **262** | **+55%** |
| 溯源率↑ | 0.9548 | 0.9213 | −3.3pp |
| 矛盾率 | 0.0000 | 0.0000 | **无编造** |
| 延迟↓ | 5723 ms | 8720 ms | **+52%** |

→ **用延迟换「答得出来」**（原始配置下一半问题答不出来）
→ ★ 意外发现：512 组三次实验空洞率完全一致，原始组有波动
  → 合并不只让结果变好，还让它**变稳**

**★★ 修掉一个真bug：「低温 ≠ 确定性」**
`do_sample = temperature > 0` → 0.1 仍是采样！
M6 报告曾写「temperature=0.1 保证可复现」是错的。
修正为 temperature=0（贪心解码），已验证同一问题 3 次输出逐字相同。

逐句定位发现是**指标测不准**，三个根因：
1. 中文答案对英文证据 → 加跨语言映射
2. `_content_tokens` **根本不切中文** → 中文免费通过
3. 正确拒答（"没有具体描述"）被判幻觉 → 加豁免

★ 走了 7 轮弯路，每轮都出新问题；

**★ 仍未解决的根本问题**（明确取舍）：
词级覆盖率对中文天然失灵。真正的解法是语义层判定（NLI），
但会引入模型依赖，与 M6「不用 LLM 判分」的立场冲突。
